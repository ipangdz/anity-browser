# Anity

Anity is a web browser for macOS, built on WebKit. It is the browser its
author works in every day: tabs and pinned sites in a sidebar, split view,
peek at a link without leaving the page, extensions, and a side panel for
notes and chat.

## Download

**[Download Anity for Mac (Apple silicon)](https://github.com/ipangdz/anity-browser/releases/latest/download/Anity.dmg)**

- macOS 26 or later, Apple silicon
- Signed with Developer ID and notarized by Apple
- No account is needed to download it or to browse with it

Open the disk image, drag Anity to Applications, and open it. Anity starts
with an address field: type a web address or a search and press Return.
It can be made the default browser in Settings › General.
